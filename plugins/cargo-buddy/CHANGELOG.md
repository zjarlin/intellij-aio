# Changelog

All notable changes to Cargo Buddy will be documented in this file.

## Unreleased

### Added

- Initial floating toolbar for current Rust crate Cargo commands.
- `publish` action for publishing the current crate.
- `publish deps` action for publishing local Cargo dependencies before the current crate.
- `show automod expansion` action for opening an in-memory `az-automod` expansion preview.
- Auto-focus for the Cargo tool window based on the active editor tab.
- Crab plugin icon for light and dark themes.
